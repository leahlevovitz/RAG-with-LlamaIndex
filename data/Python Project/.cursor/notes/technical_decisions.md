# החלטות טכניות

## בחירת מסד הנתונים

**החלטה:** SQLite  
**סיבה:** פשטות הגדרה ופיתוח מקומי — אין צורך בהתקנת שרת נפרד.  
SQLite מגיע מובנה עם Python ו-Django, מה שמאפשר להתחיל לפתח מיידית.

**מגבלות ידועות:**
- לא מתאים לסביבת ייצור עם עומסים גבוהים.
- אין תמיכה בגישה מקבילה מרובת תהליכים.

**המלצה לעתיד:** מעבר ל-PostgreSQL בסביבת ייצור — שינוי ב-`settings.py` בלבד, ללא שינוי קוד.

---

## מבנה ה-URL / API

המערכת משתמשת ב-**Django Views מסורתיים** (לא REST API).  
כל פעולה מתבצעת דרך טפסי HTML עם POST/GET.

| URL                              | פעולה                        |
|----------------------------------|------------------------------|
| `/register/`                     | הרשמת משתמש חדש              |
| `/login/`                        | התחברות                      |
| `/logout/`                       | התנתקות                      |
| `/personal_area/`                | בחירת צוות ותפקיד            |
| `/home/`                         | דף הבית עם רשימת משימות      |
| `/tasks/create/`                 | יצירת משימה (מנהל בלבד)      |
| `/tasks/delete/<id>`             | מחיקת משימה (מנהל בלבד)      |
| `/tasks/update/<id>`             | עדכון משימה (מנהל בלבד)      |
| `/tasks/assignment/<id>`         | שיוך משימה לעצמי             |
| `/tasks/update_status/<id>`      | סימון משימה כהושלמה          |

**הערה:** אין REST API כרגע. אם בעתיד יידרש, מומלץ להוסיף Django REST Framework.

## החלטות אבטחה

### הזדהות ואימות
- שימוש ב-`AbstractUser` של Django — מנגנון הזדהות מוכח ובטוח.
- סיסמאות מוצפנות עם PBKDF2 (ברירת מחדל של Django).
- הגנת CSRF מופעלת על כל הטפסים (`{% csrf_token %}`).
- `@login_required` על כל ה-Views הרגישים.

### הרשאות
- בדיקת הרשאות ב-View level: `request.user.team.admin_id == request.user.id`.
- משתמש רגיל לא יכול ליצור/למחוק/לעדכן משימות.
- משתמש יכול לשייך לעצמו רק משימות פנויות.
- משתמש יכול לסמן כהושלם רק משימות שלו.

### נקודות לשיפור
- `SECRET_KEY` חשוף ב-`settings.py` — יש להעביר למשתנה סביבה לפני ייצור.
- `DEBUG=True` — חייב להיות `False` בייצור.
- `ALLOWED_HOSTS=[]` — יש להגדיר דומיין ספציפי בייצור.

## החלטות לגבי ביצועים

- שאילתות ORM עם `filter()` ישירות — ללא N+1 בולט כרגע.
- אין pagination על רשימת המשימות — עלול להיות בעיה עם צוותים גדולים.
- אין caching — כל בקשה מגיעה ישירות למסד הנתונים.
