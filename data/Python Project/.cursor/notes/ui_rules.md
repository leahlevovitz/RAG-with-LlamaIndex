# חוקי עיצוב ממשק המשתמש

## תמיכה ב-RTL (ימין לשמאל)

כל דפי המערכת כתובים בעברית ומוגדרים עם RTL:

```html
<html lang="he" dir="rtl">
```

**חוקים:**
- כל תבנית HTML חייבת לכלול `lang="he" dir="rtl"` בתג `<html>`.
- Bootstrap 5 תומך ב-RTL באופן מובנה — אין צורך בספרייה נוספת.
- כיוון הטקסט, הכפתורים והפריסה מתאימים אוטומטית לעברית.
- אל תוסיף `dir="ltr"` לאלמנטים בודדים אלא אם יש סיבה מפורשת (כגון קוד תכנות).

## כרטיסיות (Cards)

כל תוכן מוצג בתוך כרטיסיות עם עיצוב אחיד:

```css
.soft-card {
  background: #fff;
  border: 0;
  border-radius: 22px;
  box-shadow: 0 18px 40px rgba(0,0,0,.08);
}
```

**חוקים:**
- כל בלוק תוכן עצמאי (טופס, רשימה, פאנל) יוצג בתוך `.soft-card`.
- אין להשתמש ב-`border` ישיר — רק `box-shadow` לעומק.
- `border-radius` אחיד: `22px` לכרטיסיות, `14px` לכפתורים, `999px` לאלמנטים עגולים.

## כפתורים

```css
.soft-btn {
  border-radius: 14px;
  padding: 10px 14px;
}

.soft-pill {
  border-radius: 999px;
}
```

**חוקים:**
- כפתורי פעולה ראשיים: `.btn.soft-btn` עם גרדיאנט, ללא border.
- כפתורי ביטול/ניווט: `.btn.btn-outline-secondary.soft-btn`.
- כפתורי מחיקה: `.btn.btn-outline-danger.soft-btn`.
- כפתורים מושבתים: להשתמש ב-`disabled` attribute — לא להסתיר אותם.
- כפתורים מושבתים שצריכים לשמור על עיצובם: להוסיף class `keep-style-disabled`.

## טפסים

- כל הטפסים מרונדרים עם `{{ form.as_p }}` של Django.
- שדות select משתמשים ב-`.form-select.soft-pill`.
- תאריכים מוצגים עם `<input type="date">`.
- כל טופס POST חייב לכלול `{% csrf_token %}`.

## הודעות למשתמש

הודעות מוצגות דרך מנגנון ה-messages של Django:

```html
{% for message in messages %}
  <div class="alert alert-{{ message.tags }}">{{ message }}</div>
{% endfor %}
```

**חוקים:**
- הודעות שגיאה: `messages.error(request, "...")`
- הודעות הצלחה: `messages.success(request, "...")`
- הודעות מוצגות בראש הדף, מעל כל התוכן.

## רספונסיביות

- הפריסה מבוססת על Grid של Bootstrap (`col-12 col-lg-8` וכו').
- בדף הבית: פאנל המשימות תופס `col-lg-8`, פאנל הוספת משימה `col-lg-4`.
- במסכים קטנים: כל הפאנלים מוצגים בעמודה אחת (`col-12`).
- אין breakpoints מותאמים אישית — להשתמש רק בברירות המחדל של Bootstrap.

## חוויית משתמש

- **פשטות:** כל פעולה נגישה מדף הבית — אין ניווט מורכב.
- **משוב מיידי:** כל פעולה (שיוך, סיום, מחיקה) מחזירה הודעה ברורה.
- **מניעת שגיאות:** כפתורים לא רלוונטיים מושבתים (disabled) ולא מוסתרים.
- **עקביות:** אותו עיצוב בכל הדפים — header, cards, buttons.
