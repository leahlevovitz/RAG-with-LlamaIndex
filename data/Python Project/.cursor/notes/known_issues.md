# בעיות ידועות ואזורים רגישים בקוד

## בעיה 1: אין Pagination על רשימת המשימות

**מיקום:** `Django_App/views.py` — פונקציית `home`  
**תיאור:** כל המשימות של הצוות נטענות בבת אחת ללא pagination.  
**השפעה:** בצוותים גדולים עם הרבה משימות, הדף עלול להיות איטי.  
**קוד בעייתי:**
```python
tasks = Task.objects.filter(team=user.team)
```
**פתרון מוצע:** הוספת `Paginator` של Django.

## בעיה 4: מחיקת יוצר משימה מוחקת את המשימה

**מיקום:** `Django_App/models.py` — שדה `Task.created_by`  
**תיאור:** `on_delete=CASCADE` על `created_by` — מחיקת המשתמש שיצר משימה תמחק את המשימה.  
**השפעה:** אובדן נתונים לא צפוי אם מנהל עוזב את הצוות.  
**פתרון מוצע:** שינוי ל-`SET_NULL` ו-`null=True`.

## אזורים רגישים בקוד

### `views.py` — פונקציית `personal_area`
לוגיקה מורכבת: בדיקה אם המשתמש כבר בחר צוות, שמירת המנהל לצוות.  
שינוי כאן עלול לשבור את זרימת ה-onboarding של משתמשים חדשים.

### `form.py` — `Personal_areaForm.clean()`
בדיקה אם כבר קיים מנהל לצוות. שינוי הלוגיקה עלול לאפשר שני מנהלים לאותו צוות.

### `form.py` — `Personal_areaForm.save()`
שמירת המנהל לצוות מתבצעת כאן — לא ב-View. חשוב לדעת זאת בעת debugging.
