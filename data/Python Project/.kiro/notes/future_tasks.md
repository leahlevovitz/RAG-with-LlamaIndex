# משימות עתידיות ורעיונות לפיתוח

## 1. מערכת התראות

**תיאור:** שליחת התראות בזמן אמת כאשר מתרחשים אירועים במערכת.

**אירועים מוצעים:**
- משימה חדשה נוצרה בצוות.
- משימה שויכה לעובד.
- משימה הושלמה.
- תאריך יעד של משימה מתקרב (יום לפני).

**טכנולוגיות מוצעות:** Django Signals + WebSockets (Django Channels) להתראות בזמן אמת,
או Celery Beat לבדיקות תאריך יעד תקופתיות.

---

## 2. אינטגרציה עם אימייל

**תיאור:** שליחת אימיילים אוטומטיים לאירועים חשובים.

**שימושים מוצעים:**
- אימות אימייל בהרשמה.
- שליחת סיכום שבועי למנהל עם סטטוס המשימות.
- התראה לעובד כאשר משימה חדשה זמינה.
- תזכורת לעובד כאשר תאריך יעד מתקרב.

**יישום:** הגדרת `EMAIL_BACKEND` ב-`settings.py` + שימוש ב-`django.core.mail`.

---

## 3. שיפור ביצועים בשאילתות

**תיאור:** אופטימיזציה של שאילתות ORM למניעת בעיות ביצועים עם גידול הנתונים.

**שיפורים מוצעים:**

- הוספת `select_related` לשאילתות Task כדי למנוע N+1:
```python
Task.objects.filter(team=user.team).select_related('worker', 'created_by')
```

- הוספת Pagination לרשימת המשימות:
```python
from django.core.paginator import Paginator
paginator = Paginator(tasks, 20)
```

- הוספת אינדקסים לשדות שמסוננים לעתים קרובות (`status`, `team`, `worker`).

---

## 4. ממשק ניהול מתקדם

**תיאור:** שיפור פאנל הניהול (`/admin/`) לשימוש נוח יותר.

**שיפורים מוצעים:**
- הגדרת `list_display`, `list_filter`, `search_fields` ב-`admin.py`.
- הוספת פעולות bulk (סימון מרובה כהושלם).
- תצוגת סטטיסטיקות בפאנל הניהול.

---

## 5. REST API

**תיאור:** חשיפת API לשימוש אפליקציות מובייל או אינטגרציות חיצוניות.

**טכנולוגיה מוצעת:** Django REST Framework (DRF).

**endpoints מוצעים:**
- `GET /api/tasks/` — רשימת משימות
- `POST /api/tasks/` — יצירת משימה
- `PATCH /api/tasks/<id>/` — עדכון סטטוס
- `GET /api/teams/` — רשימת צוותים

---

## 6. היסטוריית שינויים למשימה

**תיאור:** תיעוד כל שינוי שנעשה במשימה (מי שינה, מתי, מה השתנה).

**יישום מוצע:** מודל `TaskHistory` עם `ForeignKey` ל-`Task`, שמתעדכן דרך Django Signals.

---

## 7. מעבר ל-PostgreSQL בייצור

**תיאור:** החלפת SQLite ב-PostgreSQL לסביבת ייצור.

**שלבים:**
1. התקנת `psycopg2-binary`.
2. עדכון `DATABASES` ב-`settings.py`.
3. הרצת `migrate` מחדש על מסד הנתונים החדש.
4. העברת נתונים קיימים עם `dumpdata` / `loaddata`.
